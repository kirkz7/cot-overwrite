# Agent 记忆候选的第一轮本地筛查

只用 SWE-chat 本地轨迹，不用 API 或 GPU。三个检查都是探索，统计只输出汇总。按时间使用可见的记忆状态。阈值仅用于决定是否值得追加人工标注。

- 甲：以能观察到写入的 feedback 笔记为单位，要求同一记忆库后续会话有成功的显式整文件读取。至少 30 条笔记、10 个仓库才优先安排“已读后是否重复犯同类错误”的标注。单独数读后同会话有非记忆编辑工具调用的机会数。可观察的工具行为只是标注入口。
- 乙：从同一会话中实际修改两条以上已有记忆的轨迹构造代理任务。给定第一个发生修改的笔记，在它修改前已见的同库笔记中，排序预测随后同会话改了哪条。排除 MEMORY.md、未发生正文变化和目标笔记无先前快照的情形。词集合 Jaccard 对比最近观察优先，候选池固定。至少 30 个会话，且 top-3 命中率高出 10 个百分点，才有理由升级到小模型实验。共同修改是代理标签。
- 丙：比较显式整文件读取后 5 分钟内同会话成功读取另一记忆文件的比例。提醒组使用原文报告年龄，无提醒组用最近一次已观察写入估计年龄；两组都要求已观察写入并且向下取整的年龄一致，按相同年龄分层。每个层两组各至少 5 条，匹配支持至少各 30 条才报告分层差值。另读记忆文件只是行为代理，无法确认核验原始来源或识别提醒的因果效应。
# 结果

- 甲：441 条有可见写入的 feedback 笔记中，54 条在后续会话被显式整读，涉及 22 个仓库、52 个会话。46 个会话随后出现非记忆文件的编辑或写入调用。达到人工标注门槛，尚未标注适用性或错误复发。
- 乙：35 个同库会话满足要求，最近观察优先命中 22/35，词集合 Jaccard 命中 20/35，差 −5.7 个百分点。未达到升级到 8B 的门槛。没有观察到被修改的笔记不等于不需修改。
- 丙：同年龄层有重叠的样本中，提醒组 23/176，无提醒组 14/62。按各层总样本量标准化后的差为 −5.5 个百分点。年龄来自已观察写入，重叠样本有选择性，另读笔记不能证明或否定核验。
