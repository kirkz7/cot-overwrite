# Agent 续跑时的约束丢失

本地探索。Qwen3.5-9B 官方权重、运行时 4-bit、贪心、关闭思考。四种兼容性约束各六个固定实例，共 24 个检查点，全部配对。约束极性各半并轮换操作选项顺序。合成任务用受限工具接口：读取需求文件、选择一种实现，或停止。两种实现都满足显式新需求，只有一种满足该实例的兼容性约束。评测程序执行选定实现的行为并检查新需求和兼容性。两组最多三个动作，均可重读真实需求。仅替换历史工具返回的一行，保留组显示约束，丢失组用近似等长的无关记录代替。模型、仓库状态、接口、预算及提示其余部分一致。

主要指标为续跑结束的双测试通过率，报告两种方向的配对翻转数。次要指标为首个动作、重读率、无效动作、以及重读后是否通过。保留组至少 18/24 通过才解释主差值。若保留组达到该线且净差至少 5/24，记为此任务集上的初步机制信号。按四种约束分开报告，全部纳入。模型必须实际调用工具，文本叙述不计。输出量和加载失败单列。

这个设计测受控丢失，后续研究才测真实摘要器的自然遗漏。受限实现选择用于控制基本编程能力和自动判分，推断范围限于该接口和合成任务。
