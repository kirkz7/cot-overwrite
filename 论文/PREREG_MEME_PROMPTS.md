# MEME 提示词基线预注册：已发表的提示词能把本地读者拉到多高

写于 2026-11-10，在任何新提示词作答之前。这是**基线测量**，不是我们的方法。接在 `PREREG_MEME_READER.md` 之后（官方提示词下 Qwen3-8B 真通过率：只给证据时级联 0 / 失效 0 / 删除 6.7，思考后 34.7 / 5.0 / 30.0）。

## 0. 先澄清：上次说"和 RAW-RAG 的数对不上"，原因查到了

上次我写"RAW-RAG 报告 Qwen3.5-35B 全证据失效题 93.85，这里只有 5%，它的提示词和过滤规则没有核对"。现在核对了论文附录 C.5、D.1.3、G.6、G.11、G.12 和它的代码：

- **失效题对不上，是因为它在这一类上换了提示词。** 表 2 的"全证据"条件里，失效题单独加了一段"依赖有效性规则"（附录 G.11），直接告诉读者"依赖变了且没有新值时，就答 I don't have that information"。其余题型用官方提示词。所以它的 36 / 92 / 94 是"被告知题型 + 加了规则"的数，我的 5% 是官方提示词的数，不是同一个条件。
- **级联和删除其实对得上。** 同样只给证据、同样官方提示词、同样做前置过滤：它的 GPT-4o-mini 级联 1.83、Qwen3.5-35B 39.63；我的 8B 不思考 0、思考 34.7。删除它是 39 / 46，我是 6.7 / 30.0，偏低但同一量级。
- 作答提示词（MEME 官方原文）和"前置题也要对"的过滤规则，两边一致。它的全证据条件也是"提问位置之前的全部标注证据会话，按时间排"，和我的 `oracle` 一致。
- 仍然不同的：判分模型（它 gpt-4o-mini，官方 gpt-4o，我本机 14B）；读者；它的两个开源读者是否开思考，论文我读到的部分没有写。
- 它的任务策略（附录 G.12）里有一条前置题规则："条件替换是假设性的，不得激活"。说明它也碰到了我上次事后看到的现象（读者把"如果…就会是 Y"当成现状）。

## 1. 要回答的问题

训练读者之前必须知道：只改提示词，同一个读者能到多少？如果提示词就够，训练没有理由。

## 2. 提示词（全部是别人论文的原文，不是我写的）

|---|---|---|---|

## 3. 其余设置

和 `PREREG_MEME_READER.md` 相同：探索集 30 集；读者 Qwen3-8B（4-bit）；上下文 `oracle`（只给证据会话）和 `rag`（重排前 15）；判分用 MEME 官方提示词，判分模型本机 Qwen3-14B；真通过 = 后置题对且同一提示词、同一上下文下的前置题也对。`hop` 不跑。

**新增"不伤害"检查**：精确回忆题（ER，前置 30 + 后置 30），只在 `oracle` 上跑，按 MEME 官方做法用子串匹配判分。`official` 也补跑这 60 题作参照。

先跑 `oracle`（短，约 3 小时），再跑 `rag`（约 4–5 小时）。如果时间不够，`rag` 的思考部分最后跑，没跑完如实写。

## 4. 事先写下的预测和判定线

主指标：`oracle` 上的真通过率，只看**可部署**的提示词（`g11`、`smw`；`g12` 不算）。

- **判定线（对"要不要训练读者"）**：
  - 某个可部署提示词在级联和失效上**都** ≥ 70%，且 ER 不低于 `official` 5 个点以上：提示词就够了，训练读者在这个基准上没有理由。
  - 最好的可部署提示词在级联或失效上 ≤ 40%：提示词不够，有明确空间。
  - 之间：有空间但不大，训练要赢的是这个提示词而不是官方提示词。
- **预测**：
  - P1 `g11` 不思考：失效 ≥ 40%；级联 ≤ 10%（规则只教"不要报旧值"，而且字面上会让读者在级联题上也拒答）；删除 ≤ 15%。
  - P2 `g12` 不思考（被告知题型）：删除 ≥ 60%，级联 ≤ 40%，失效 ≤ 50%。（参照：RAW-RAG 的 GPT-4o-mini 在类似条件下 92 / 34 / 28。）
  - P3 `smw`：级联 ≥ 35%（不低于思考）；失效 ≤ 30%；`smw` 减 `ctrl` 在级联上 ≥ +10 个点。
  - P4 所有新提示词的 ER 都不低于 `official` 5 个点以上。
  - P5 `rag` 上各提示词的级联、失效都不高于各自 `oracle` 的数。
- 只报告、不设线：各提示词的前置题正确率（提示词如果让读者在变更前就拒答，会被前置过滤扣掉）；原始通过率；没答完的条数。

限制事先写明：一个读者；判分模型不是官方的，前置题和删除题上次一致率低于 90%，只能当参考；思考单次采样；30 集；探索集上的数不是任何方法的证据。
