# MEME 读者试验预注册：证据取到之后，本地读者答对多少

写于 2026-11-10，在任何读者作答之前。这是**诊断**，不是修复。接在 `PREREG_MEME_PILOT.md` 之后：那次只量了证据覆盖率，"缺口在读者"是拼别人论文的数推出来的，这次在同一批检索结果上直接量。

## 1. 要回答的问题

- Q1：检索结果不变，Qwen3-8B 在级联 / 失效 / 删除题上答对多少？其中证据已齐的那部分题答对多少？
- Q2：只给证据会话（不含干扰）时答对多少？这是这个读者的上限。
- Q3：把缺的触发事件补进去（9 + 6 上游检索），正确率涨不涨？
- Q4：打开思考后变多少？这决定"训练读者"要补的是"会不会推"还是"推不推"。

## 2. 数据

探索集 30 集（`pl_001`–`pl_015`、`sw_001`–`sw_015`），后置题：级联 49、失效 40、删除 30。70 集留出集不碰。检索结果直接用上次存下的 `dense_*.json` / `rerank_*.json`，不重跑。个人生活域干扰会话来自 LongMemEval，只输出统计数。

## 3. 条件

上下文三种（都按时间顺序排，带会话时间）：
- `rag`：重排前 15 个窗口，每个窗口扩成它碰到的完整消息。
- `hop`：原问题前 9 个 + 上游检索 6 个（规则同上次；用了数据里的上游实体名，只是诊断）。只对级联和失效题有区别。
- `oracle`：提问位置之前的全部证据会话（5 个），不含干扰会话。

读者：Qwen3-8B（本机 4-bit）。两种解码：不思考（贪心，最多 500 token）；思考（Qwen3 模型卡的采样参数，按题固定随机种子，最多 1024 + 500 token）。思考只跑 `rag` 和 `oracle`，不跑 `hop`（省时间）。

作答提示词：MEME 官方的统一提示词原文（"Answer the user's question based ONLY on the context… Answer with ONLY the value."）。

判分：MEME 官方的各题型判分提示词原文，判分的金标用 `entity_values`（和官方代码一致）。**判分模型是本机 Qwen3-14B（4-bit，不思考），不是官方的 gpt-4o。**

"真通过"（MEME 的规则）：后置题判对，并且同一实体的前置题（同样的问题，在变更之前问）也判对。前置题的上下文：`oracle` 用变更之前的证据会话；`rag` 用同一份重排名单里位于前置提问位置之前的窗口取前 15（近似：没有对截短的历史重新检索）；`hop` 沿用 `rag` 的前置结果。同时报告不加这条规则的原始通过率。

## 4. 和已发表做法的差别

1. 读者是 4-bit 的 Qwen3-8B，RAW-RAG 和 MEME 用的是 API 模型。
2. 判分模型换成了本机 14B。补救：对规则明确的三类（前置题含旧值、级联含新值、删除不含被删值）另算字符串规则，报告和判分模型的一致率；一致率低于 90% 的那一类，结论只能当参考。
3. `rag` 把窗口扩成完整消息后中位数约 8k token、最长约 15.5k（不加载模型量的长度）。RAW-RAG 的具体展示格式和长度不同。
4. 检索模型是 Qwen3，不是 RAW-RAG 在 MEME 上用的那一对（同上次）。
5. 思考模式用采样，单次运行，没有多种子。

## 5. 事先写下的预测和判定线

指标是真通过率，区间用按集重采样的自助法（10000 次）。

- **主指标 P1：不思考，`rag`，级联题里完整路径已在前 15 的那 37 题。** 预测 ≤ 20%。
  - ≤ 30%：证据齐了也答不对，读者是这个模型的主要缺口，上次的推断成立。
  - ≥ 60%：推断不成立，证据齐了这个读者基本能答对，要重新考虑。
  - 之间：两边都有份。
- **P2：不思考，`oracle`。** 预测级联 ≤ 30%、失效 ≤ 40%、删除 ≤ 50%。（参照：RAW-RAG 报告 GPT-4o-mini 全证据是 2 / 36 / 39。）
- **P3：思考对级联的作用（`oracle`，思考 减 不思考）。** 预测 ≥ +20 个点。
  - 思考后级联 ≥ 70%：小模型会推，只是默认不推。训练读者的目标清楚（把这步推理变成默认行为）。
  - 思考后级联 ≤ 30%：小模型不会推，是能力问题，训练更难。
  - 之间：不确定。
- **P4：补触发事件（`hop` 减 `rag`，不思考，级联）。** 预测 < +10 个点（读者不会用）。
- **P5：`rag` 里完整路径没进前 15 的级联题。** 预测真通过率 ≤ 10%（检验上次的覆盖率判定有没有用）。
- 失效和删除的其余数字只报告，不设线。

样本量小（级联 49 / 失效 40 / 删除 30，其中证据齐的级联 37 题），区间会很宽。结果如实报告，看过结果后不改规则；必须改就写成补记并注明。
